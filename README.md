# Vision Lab Manual QC — Chrome extension

A review panel for the Vision Lab platform: open a video, rate six quality topics, press **Enter**, and the next video opens automatically.

## 📥 Install (one time, ~2 minutes)

1. **[⬇ Download the extension (zip)](https://github.com/sahdevlw/vision-lab-qc-extension/releases/latest/download/vision-lab-manual-qc.zip)** and **unzip it** somewhere you won't delete (e.g. Documents).
2. In Chrome, type `chrome://extensions` in the address bar and press Enter.
3. Turn on **Developer mode** (switch in the top-right corner).
4. Click **Load unpacked** (top-left) and select the unzipped folder.
5. Open any video on **vision-lab.linewise.io** — the Manual QC panel appears.

## 🔄 Updating

When a new version is announced, download the zip again, unzip it **over the same folder**, then on `chrome://extensions` click the ↻ reload icon on the extension's card. (One-click automatic updates via the Chrome Web Store are coming soon.)

## Requirements

- Google Chrome (or Edge) on desktop
- A Vision Lab account with access to the footage you're reviewing — the extension uses your normal platform login and can only see what you can see
